# Weak Internal Demand in Mexico – Econometric Analysis

> Academic project developed as part of a team.

## Objective
Analyze weak internal demand in Mexico using macroeconomic variables and econometric modeling.

## Data
Seven macroeconomic variables related to consumption, income, prices, and financial conditions in Mexico.

## Methodology
- Exploratory data analysis of macroeconomic indicators.
- Model selection through statistical tests.
- Estimation of a VAR(1) model.
- Generation of forecasts to analyze internal demand dynamics.

## Tools
- R

## Results
The VAR model captures the dynamic relationships between macroeconomic variables and allows forecasting internal demand behavior.
